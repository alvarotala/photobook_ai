# Preferencias de colaboración

- Tomar como hechos las observaciones del usuario sobre resultados de ejecución, archivos o imágenes.
- No volver a comprobar esas observaciones salvo que el usuario pida explícitamente verificar algo.
- Mantener la depuración enfocada y sencilla; no agregar validaciones, pantallas o complejidad no solicitadas.
- No instalar dependencias: proporcionar los comandos para que el usuario los ejecute.
